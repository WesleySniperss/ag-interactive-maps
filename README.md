## 🗺️ Інтерактивні карти від Adventure Guys

Інтерактивні карти D&D для Foundry VTT українською: Баровія, Брама Балдура, Вотердіп, Лускан, Невервінтер, Узбережжя Мечів, Сигіл і Зовнішні землі, Тей та Чалт.

Назви сцен, папок і журналів, а також описи всіх локацій перекладено українською.
Пригоди імпортуються з компендіуму «🗺️ AG Інтерактивні карти».

Для роботи потрібен модуль Monk's Active Tiles.
